工作流程

  1. 拍／找該業者公車的側面或斜前方照片，載入上方。
  2. 右邊逐部位點選取色；選填部位留空＝沿用括號內部位顏色。調整車長、保險桿、閃電、車頂箱。
  3. 填塗裝 id、名稱、屬於此車型的車牌 (已確認的車)，和比對規則 (路線、車牌正則、業者名稱，留空＝不限；涵蓋還沒確認車牌的車)。
  4. 按「下載 livery.json」覆蓋 data/livery.json；或複製「此塗裝 JSON」手動合併。
  5. 本機導航測試頁確認後 commit。

3. 塗裝與比對規則

載入既有 塗裝 id 名稱 備註 車牌 路線 車牌正則 業者

比對順序：先查車牌清單 (已確認車型，任何路線都適用；同一車牌只能屬於一種車型，填在這裡會從其他車型移過來)，查不到再比對規則。

規則由上往下比對，第一條符合的生效：有車牌條件的新規則放最上面，其餘放最後。三項都留空＝不新增規則。
