# 臺中公車捷運即時路線圖

以捷運路線圖風格呈現臺中市主要公車路廊與捷運綠線，並提供全市公車站位／路線查詢。資料來自交通部 TDX 運輸資料流通服務。

**線上展示**：部署後網址為 `https://<帳號>.github.io/Schematic-Transit-Taichung/`

## 功能

### 路線圖（`taichung.html`）
- 15 條公車路廊＋捷運綠線的示意路線圖，橫式與直式（北朝上、手機滿版）各一套版面
- 線寬依路廊班次密集程度分三級；所有線段只有水平、垂直與 45°
- 公車位置依即時預估到站時間推算；點路廊展開各路線的平行線
- 點站牌：依行車方向分欄的到站卡片、與每日營運時刻表比較早到／晚到
- 點路線：整條路線各站即時資料與全日時刻表
- 行程規劃：選起訖站，列出直達或轉乘 1～2 次的方案；上車時間只採用 API 提供的時刻

### 查詢（`taichung-query.html`）
- 全市站位 → 站牌（依行車方向分組）各路線的即時到站與時刻表
- 全市公車路線的即時資訊、未來 7 日各站時刻表、公車即時位置
- 捷運綠線路線簡圖、實際線形與車站位置、依班距推算的各站時刻表
- 地圖可持續顯示自己的位置
- 即時到站在 15 分鐘內顯示倒數（分秒），超過 15 分鐘改顯示預估到站時刻 HH:MM
- 下一班過了表定發車時間 10 分鐘仍沒有車發出（要先按「比對準點／遲發」載入車輛班次），標示「未依時刻表發車」；依回站車輛推估的「預估延遲發車」在能把班次對應到車牌前暫停顯示
- 標題列右側：捷運風格路線圖、外觀切換（月亮＝深色、太陽＝淺色）、地圖圖層；手機上圖層卡片與標題列同寬，右上 × 關閉

### 站站時刻表的來源
中途站的時刻只用以下兩種，沒有就顯示「本站無預估班表」（起站仍列發車時刻），不用直線距離或即時預估去推估：
- 發車時刻（路線班表／每日營運時刻表）＋TDX 站間旅行時間
- 站站推估班表（V3，近 3 個月歷史）或 TDX 時刻表本身給的各站時刻

### 路徑規劃（查詢頁「規劃」）
- 上下車時刻只用：即時預估到站（標「即時」），或路線班表＋站間旅行時間（標「表定」）
- 沒有站間旅行時間的路線，只能搭即時預估中有到站時刻的車，下車時刻用同一台車的預估；起點附近有這類路線的車時，另查該路線即時（最多 3 條）。未來日期不會排入這類路線
- 已載入路線即時的段落都用即時判斷誤點、早到、末班已過
- 選取方案時查各轉乘路線即時；停駛、車已過站、晚到 5 分以上或原預估的車已不在即時資料中，就從前一段下車站重新規劃，立即列出最多 2 個當下可行的替代方案，可一鍵改用

## 使用前：設定 TDX 金鑰

即時資料需要 TDX API 金鑰。網頁不內建金鑰，請自行到 [tdx.transportdata.tw](https://tdx.transportdata.tw/) 免費註冊，在「會員中心 → API 金鑰」取得 Client ID 與 Client Secret，再點網頁左上角的「🔑」貼上。

- 金鑰只存在你自己的瀏覽器（localStorage），不會傳到其他地方。
- 未設定金鑰時，路線圖、站牌、路線站序仍可瀏覽，只是沒有即時資料與時刻表。
- 程式限制每分鐘最多呼叫 3 次 API（兩個頁面共用計數），並快取結果以節省額度。

## 檔案

| 檔案 | 內容 |
|---|---|
| `taichung.html` | 路線圖主頁 |
| `taichung-query.html` | 站位／路線查詢頁 |
| `taichung-routes.js` | 停靠路廊站牌的路線站序與累積距離（路線圖用） |
| `taichung-network.js` | 全市站牌、站位、路線站序與捷運資料（查詢頁用） |
| `bus3d.js` | 導航 3D 公車共用車身與塗裝比對 |
| `data/livery.json` | 3D 公車塗裝與比對規則（路線／車牌／業者） |
| `tools/livery.html` | 3D 公車塗裝編輯器（由照片取色） |

靜態檔由 TDX 資料於 2026-11-10 產生，路線改道或增減站牌時需重新產生。

## 新增 3D 公車塗裝

導航畫面裡，符合 `data/livery.json` 規則的公車顯示成 3D 模型，其餘用公車圖示。新增車款：

1. 準備該車款的側面或斜前方照片。
2. 開 `tools/livery.html`（建議由網站開啟；用本機檔案開啟時按「開啟 livery.json…」選 `data/livery.json`）。
3. 載入照片，右邊點選部位後點照片上對應位置取色，取完自動跳下一個部位；調整車長、保險桿、車頭閃電、車頂箱，看預覽確認。
4. 填塗裝 id、名稱、屬於此車型的車牌（已確認的車），與比對規則（涵蓋還沒確認車牌的車）：路線（可多條，逗號分隔）、車牌正則（例 `^EAL`）、業者名稱（名稱包含即符合）；留空＝不限。
5. 按「下載 livery.json」覆蓋 `data/livery.json`。

比對順序：先查車牌清單（`plates`，任何路線都適用），查不到再比對規則；規則由上往下比對，第一條符合的生效，車牌條件較細的規則要放在同路線的一般規則前面。車身為方塊組成，只表現大塊配色。

## 資料與圖資來源
- 公車、捷運資料：[交通部 TDX 運輸資料流通服務](https://tdx.transportdata.tw/)
- 底圖：[內政部國土測繪中心](https://maps.nlsc.gov.tw/) 通用版電子地圖
- 地圖元件：[Leaflet](https://leafletjs.com/)

## 已知限制
- 未來日時刻表只依 TDX 路線班表的星期設定，未考慮國定假日。
- 約 185 條路線（346 個子路線方向）沒有 TDX 站間旅行時間，中途站沒有時刻表；路徑規劃只在有即時預估時才會使用這些路線。
- 臺中捷運沒有逐站時刻表，各站時刻依官方班距與站間行駛時間推算。
- 金鑰在瀏覽器端使用；若要多人共用同一把金鑰，應改由自己的伺服器代理 API。
